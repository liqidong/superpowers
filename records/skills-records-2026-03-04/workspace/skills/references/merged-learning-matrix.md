# Merged Learning Matrix

更新时间：2026-03-04

## 目标
把“现有技能体系”与 `peterlearning` 打通，形成单入口执行链路。

## 当前技能
- `peterlearning`

## 合并映射

| 场景 | 先用现有技能 | 再用 `peterlearning` | 输出 |
|---|---|---|---|
| 新任务起步 | `brainstorming` / `writing-plans` | 原型回路 | 可运行原型 |
| 配置或部署变更 | `verification-before-completion`(收尾) | 变更合约回路 | 可审计变更记录 |
| 故障排查 | `systematic-debugging` | 证据调试回路 | 根因与修复证据 |
| 每日收尾 | `verification-before-completion` | 主子日志回路 | 主日志+子笔记 |
| 流程固化 | `writing-skills` | 打包沉淀回路 | 新 SKILL + 脚本 |

## 建议执行顺序（默认）
1. 进入 `peterlearning`
2. 原型回路
3. 变更合约回路
4. 证据调试回路
5. 主子日志回路
6. 打包沉淀回路

## 合并原则
- 现有技能负责“通用方法纪律”，`peterlearning` 负责“你的日常任务语境”。
- 冲突时优先：安全、可回滚、可验证。
- 旧 `lqd` 模式不再作为后续学习方式。
